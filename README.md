# 아이크미톡 시안 (프로토타입)

아이크미 프랜차이즈 통합 플랫폼(아이크미톡)의 **화면 시안**이에요.

- 열어 보기: https://rnlfuf1234-ship-it.github.io/icme-talk/
- 처음 화면은 로그인이에요. 아이디와 비밀번호는 담당자에게 받아요(선생님 · 학부모 · 센터장 · 본사).
- 처음이면 로그인 화면의 **회원가입**으로 신청해 볼 수 있어요(학부모 · 선생님 · 센터장). 본사가 승인해야 로그인돼요. 시안이라 신청 내용은 **그 브라우저 안에만** 저장되고 다른 기기로는 전해지지 않아요.
- **실제 서비스가 아니에요.** 서버가 없어서 로그인은 "화면 접근 제어"를 보여 주는 시연이고, 눌러 본 내용은 보는 사람의 브라우저에만 저장돼요.
- 아이·교사·원생 이름과 숫자는 모두 가상이에요. **실제 아이 정보나 실제 이름·전화번호를 입력하지 마세요.**
- 센터 이름과 본사 화면의 "가맹점 점검" 결과만 실제예요. 점검 결과는 본사 비밀번호로 암호화돼 있어서 본사 계정으로만 볼 수 있어요.
